# MadDevs — тестовое задание (Agentic Developer)

Репозиторий тестового задания для отбора на позицию Agentic Developer в MadDevs.

## Структура репозитория

- `context/` — исходные материалы: письмо с условиями отбора (`E-mailText.md`), чеклист обязательных требований к сдаче (`PROJECT_REQUIREMENTS.md`), файл с описанием всех 14 кейсов (`Задания Agentic Developer.pdf`).
- `logs/` — журналы работы:
  - `SESSION_LOG.md` — подробная запись промптов и ответов ИИ-агента по ходу всей работы.
  - `DECISIONS_LOG.md` — ключевые решения и действия с атрибуцией (кто сделал — я или агент) и таймкодами.
- код проекта — будет добавлен после выбора и согласования конкретного кейса.

## Статус

Кейс из 14 предложенных пока не выбран, срок сдачи не согласован с MadDevs. Актуальный статус и открытые вопросы — в `logs/DECISIONS_LOG.md`.

## Инструменты

Разработка ведётся с помощью Claude Code (модель Claude Sonnet 5). Подробное обоснование выбора инструмента и модели будет зафиксировано после выбора кейса и начала реализации.
