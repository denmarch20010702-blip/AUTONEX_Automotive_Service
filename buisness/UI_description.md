При входе в приложение клиенту предлагается выбор услуг, в виде больших квадратных кнопок с скругленными углами бледно-зеленого цвета и минималистичными пиктограммами позиционируются кнопки по середине страницы, для интуитивно понятного пути. Так же в верхнем правом углу есть кнопка которая переводит на регистрацию/ авторизацию
После выбора услуги, в виде таких же кнопок мелкого размера, расположенных в виде таблицы, с разбиением на утро, день, вечер и ночь. предлагается выбрать время, с написанными на них датами и временем в формате:
DD.MM.YYYY - 00:00
Границы диапазонов: утро — с 04:00 по 10:00, день — с 10:01 по 16:00, вечер — с 16:01 по 22:00, ночь — с 22:01 по 04:00 (переходит через полночь).
При выборе слота, если клиент не авторизован, предлагается войти или создать учётную запись, чтобы добавить имя клиента и автомобиль, для бронирования записи.
Чтобы созать учётную запись клиенту предлагается поле для регистрации/авторизации. включающее в себя почту и Имя пользователя.
в личном кабинете чтобы добавить автомобиль, клиент нажимает на кнопку с минималистичной пиктограммой автомобиля красного цвета и знаком плюс, а так же текстом "добавить автомобиль"
далее появляется форма заполнения данных автомобиля, можно вводить вручную, или выбрать марку и модель из выпадающего списка, при ручном вводе, сокращается количество доступных вариантов из выпадающего списка, если есть совпадения по названию или модели автомобиля. пробег заполняется вручную. Дату последнего обслуживания можно заполнить вручную в формате DD.MM.YYYY или выбрать в удобном календаре.
Выпадающих списков должно быть два: первый — только марки авто, второй — только модели, соответствующие уже выбранной марке (модель нельзя выбрать раньше марки).
После выбора слота, предлагается кнопками выбрать один из автомобилей который клиент хочет записать.
При полном наборе данных, высвечивается сообщение о успешной брони, и напоминание о визите в указанное время.
Весь интерфейс выполнен в минималистичном дизайне, используются пиктограммы соответствующие описаниям кнопок, цвет для кнопок выбран бледно-зеленый, основной фон белый.
Самостоятельно клиент нигде не вводит ID номера, всё присваивается на кнопки.
